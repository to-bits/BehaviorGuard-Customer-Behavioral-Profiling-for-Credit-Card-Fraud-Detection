INTERPRETATION
--------------
1. The dataset is extremely imbalanced, so PR-AUC, recall, precision and F1 are more informative than accuracy alone.
2. Several anonymized V-features show very strong statistical separation between normal and fraudulent transactions.
3. Engineered behavioral features should be interpreted as complementary signals rather than automatically assuming they are individually strong fraud predictors.
4. Statistical significance is interpreted together with effect size because the dataset is large.
5. The XGBoost threshold is selected on validation data and the test set is used only for final evaluation.
